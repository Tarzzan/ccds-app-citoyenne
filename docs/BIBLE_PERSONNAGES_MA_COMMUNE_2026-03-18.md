# Bible Personnages Ma Commune

## But

Definir une base claire pour produire un duo visuel fort, stable et reutilisable dans toute l experience `Ma Commune`.

Cette bible sert a :

- guider la generation IA
- garder une coherence entre les images
- eviter la derive gadget
- preparer une vraie integration produit

## Architecture Des Personnages

Le systeme cible repose sur deux figures.

### 1. Mascotte Territoriale

Fonction :

- emotion
- memorisation
- accueil
- gratitude

Cette figure doit porter la chaleur du produit et l attachement a l application.

### 2. Agent Communal Illustre

Fonction :

- confiance
- explication
- cadrage
- presence de service public

Cette figure doit porter la credibilite et le lien avec la commune.

## Regle De Duo

La mascotte ne remplace pas l agent.
L agent ne rend pas la mascotte inutile.

Le duo fonctionne ainsi :

- mascotte pour accueillir, remercier, relancer, valoriser
- agent pour expliquer, orienter, rassurer, documenter

## Piste De Casting Recommandee

### Piste A - Mascotte Oiseau Local

Intention :

- creature vive
- chaleureuse
- agile
- lisible en petit

Atouts :

- silhouette memorable
- declinaison facile en avatar, sticker, scene
- expression riche

Risque :

- tomber dans le cute generique si le rendu n est pas premium

### Piste B - Mascotte Esprit Du Territoire

Intention :

- figure symbolique inspiree de la Guyane
- plus graphique
- plus institutionnelle

Atouts :

- univers fort
- tres identitaire

Risque :

- moins immediate
- plus difficile a rendre attachante

### Piste C - Mascotte Mammifere Urbain Tropical

Intention :

- personnage plus doux
- plus incarnable
- plus expressif

Atouts :

- bon potentiel emotionnel
- bon potentiel animation

Risque :

- moins specifique territorialement si mal dirige

## Choix Recommande

Commencer par :

- une mascotte animale locale ou tropicale tres stylisee
- un agent communal humain semi-realiste

Ce couple donne la meilleure combinaison entre :

- memoire
- proximite
- credibilite
- potentiel commercial

## Agent Communal

### Profil Cible

- 28 a 45 ans
- allure sobre
- visage bienveillant
- lisible immediatement comme service public local

### Vestiaire

- tenue simple et propre
- veste ou polo municipal discret
- badge ou signe communal sobre
- palette verte, terre, sable, bleu fleuve

### Attitudes A Produire

- accueillir
- ecouter
- montrer une carte ou un dossier
- remercier
- pointer une etape
- rassurer

## Mascotte

### Qualites Attendues

- silhouette forte
- lisibilite en petit
- tres bonne expressivite du visage
- capacite a exister en scene et en icone

### Attitudes A Produire

- saluer
- observer le territoire
- remercier
- pointer une action
- celebrer une resolution
- accompagner l attente

## Style Visuel

Le rendu cible doit etre :

- semi-realiste
- premium
- narratif
- chaleureux
- lumineux

Le rendu ne doit pas etre :

- emoji-like
- clipart
- flat design banal
- cartoon enfantin

## Cohérence De Lumière

Chaque visuel personnage doit retrouver :

- une lumiere tropicale douce
- des ombres chaudes
- des verts profonds
- des terres rouges ou sables clairs
- une atmosphere humide mais accueillante

## Expressions Clefs

Les deux personnages doivent pouvoir exister avec :

- accueil
- gratitude
- attention
- vigilance
- encouragement
- satisfaction

Eviter :

- sourire permanent artificiel
- posture trop commerciale
- comique outrancier

## Niveau De Réalisme

Le bon niveau n est ni photorealiste ni cartoon simple.

Le bon niveau est :

- assez realiste pour inspirer confiance
- assez stylise pour rester iconique
- assez doux pour etre engageant

### Agent

- trois quarts avec tablette ou dossier
- geste d explication
- geste de remerciement
- geste de pointage d une etape
- posture calme de suivi

## Regles D Integration Produit

### Mascotte

Surfaces recommandees :

- onboarding
- login
- inscription
- etats vides
- remerciements
- notifications positives

### Agent

Surfaces recommandees :

- detail signalement
- mises a jour de statut
- bilan citoyen
- dashboard admin
- panneaux d explication

### Duo

Surfaces recommandees :

- hero de landing
- campagne de demonstration
- visuels stores

## Règles D Asset

Produire pour chaque personnage :

- une version hero verticale
- une version buste
- une version horizontale
- une version fond transparent
- une version reduite

## Critères De Validation

Un personnage est retenu si :

- il est memorable sans texte
- il reste lisible a petite taille
- il peut vivre en scene et en interface
- il inspire confiance au lieu de paraitre enfantin
- il augmente la desirabilite du produit

## Decision De Production

Ne pas lancer de production de masse sans avoir valide :

- 3 pistes mascotte
- 2 pistes agent
- 1 palette definitive
- 1 logique de lumiere commune
