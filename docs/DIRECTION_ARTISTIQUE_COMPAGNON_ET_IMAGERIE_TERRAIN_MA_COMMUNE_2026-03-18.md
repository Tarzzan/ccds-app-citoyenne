# Direction Artistique Compagnon Et Imagerie Terrain Ma Commune

## Intention

Faire passer `Ma Commune` d une application utile mais encore heterogene a une experience civique premium, memorable et emotionnellement engageante.

Le produit ne doit plus reposer sur :

- une mascotte abstraite trop legere
- des icones, emojis et badges confondus
- des categories qui racontent mal la realite du terrain

Il doit reposer sur un univers visuel fort, lisible et commercialisable.

## Vision

`Ma Commune` doit devenir un compagnon civique du quotidien.

Le citoyen ne doit pas sentir :

- un portail froid
- un ticketing municipal deguise
- une succession d ecrans sans ame

Il doit sentir :

- une commune attentive
- un service public proche
- une application belle, claire et rassurante

## Concept Directeur

Construire un duo visuel complementaire :

- une mascotte territoriale iconique
- un agent communal illustre et credible

La mascotte porte :

- l attachement emotionnel
- la memorisation
- la chaleur

L agent porte :

- la confiance
- l explication
- la credibilite institutionnelle

Le systeme ne doit pas choisir entre mascotte et agent.
Il doit orchestrer les deux.

## Direction Creative

Le rendu cible doit evoquer un cinema d animation premium, chaleureux et tres soigne, sans copier une oeuvre ou un studio precis.

Il faut viser :

- silhouettes fortes
- visages expressifs
- lumiere chaude et tropicale
- textures naturelles
- composition cinematographique
- palette guyanaise maitrisee

Il faut eviter :

- le kawaii gadget
- le style enfantin
- le cartoon web generique
- les personnages trop institutionnels et rigides

## Ancrage Guyanais

Le produit doit raconter la Guyane reelle sans folklore caricatural.

Elements de terrain a integrer :

- chausses usees, nids de poule, bords de route humides
- vegetation dense, racines, feuilles, ombres tropicales
- pluies intenses, flaques, boue, eaux de ruissellement
- lampadaires, grilles, signalisation, mobilier communal
- beton, latérite, peinture usee, panneaux, trottoirs

Elements de tonalite a viser :

- territoire vivant
- climat humide
- chaleur humaine
- dignite du service public

## Personnages A Produire

### 1. Mascotte Territoriale

Mission :

- etre l embleme de l application
- remercier
- accueillir
- accompagner les moments d attente

Profil attendu :

- memorable
- attachante
- locale
- sobre
- premium

Elle doit pouvoir exister :

- en portrait
- en buste
- en scene
- en version reduite pour les notifications ou cartes de guidance

### 2. Agent Communal Illustre

Mission :

- incarner la commune qui repond
- expliquer les etapes
- rassurer sur la prise en charge

Profil attendu :

- professionnel
- bienveillant
- lisible
- credible
- proche du terrain

Il peut etre decliné :

- en agent voirie
- en agente de relation usager
- en binome terrain si utile

## Architecture Visuelle A Respecter

Le systeme visuel doit etre separe en trois couches distinctes.

### Couche 1. Icônes Fonctionnelles

Usage :

- navigation
- actions
- statuts
- boutons

Contraintes :

- tres lisibles
- simples
- monochromes ou bicolores
- sans emoji

### Couche 2. Badges Categories

Usage :

- cartes categorie
- listes
- detail signalement
- back-office

Contraintes :

- plus identitaires que les icones fonctionnelles
- reconnaissables en petit
- jamais confondus avec des emojis
- derives d un systeme coherent

### Couche 3. Illustrations Editoriales Terrain

Usage :

- onboarding
- ecrans vides
- remerciements
- bilans
- categories
- campagnes de demonstration

Contraintes :

- scenes dessinees realistes ou semi-realistes
- emotion et contexte
- vraie narration du terrain

## Scenes Prioritaires A Produire

### Voirie

- nid de poule profond apres pluie tropicale
- fissure ou affaissement de chaussee

### Eclairage public

- lampadaire en panne a la tombee du jour
- zone pietonne faiblement eclairee

### Proprete

- depot sauvage en bord de voirie
- poubelle debordante ou point d apport degrade

### Inondations et reseaux

- bouche d egout bouchee
- ruissellement ou accumulation d eau

### Espaces verts

- vegetation qui envahit trottoir ou passage
- arbre ou branche menaçante

### Mobilier urbain

- banc casse
- abri ou equipement public degrade

### Signalisation et securite

- panneau endommage
- danger de circulation ou obstacle

### Batiments communaux

- facade ou acces public degrade
- desordre visible a traiter

## Moments Relationnels A Habiller

Le duo mascotte + agent doit apparaitre aux moments suivants :

- premier lancement
- configuration serveur
- inscription
- creation d un signalement
- remerciement apres envoi
- mise a jour de statut
- notification importante
- bilan citoyen
- etat vide utile

## Règle Narratif

Chaque visuel doit raconter une situation.

Il ne suffit pas de montrer :

- un trou
- une poubelle
- un lampadaire

Il faut montrer :

- une scene
- un contexte
- une consequence
- une raison d agir

## Ambition Commerciale

Le resultat doit permettre a une mairie de dire :

- cette application est belle
- cette application inspire confiance
- cette application respecte les habitants
- cette application donne envie de signaler utilement

L univers visuel doit etre assez fort pour :

- une demonstration elu
- un salon de collectivites
- une page de garde commerciale
- des stores mobile

## Pipeline De Production

### Lot 1. Character Design

- concevoir 3 pistes de mascotte
- concevoir 2 pistes d agent communal
- choisir un duo final

Livrables :

- planches de silhouettes
- expressions
- palettes
- poses clefs

### Lot 2. Système D Icônes Et Badges

- supprimer toute ambiguite emoji vs icone
- redefinir les badges categories
- harmoniser mobile, admin et web

Livrables :

- set fonctionnel
- set categories
- catalogue gouverne

### Lot 3. Imagerie Terrain

- produire les scenes realistes prioritaires par categorie
- brancher les illustrations sur onboarding, etats vides et categories

Livrables :

- illustrations hero
- cartes categories
- etats vides
- visuels de remerciement

### Lot 4. Animation Et Presence

- animations d entree tres legeres
- transitions de gratitude
- respiration des ecrans de suivi

Livrables :

- principes de motion
- variantes mobile compatibles performance

## Règles Pour La Génération IA

Objectif :

- utiliser les meilleurs generateurs d image disponibles
- produire un niveau premium constant
- garder une gouvernance claire

Interdits :

- copier explicitement un studio ou un artiste
- melanger emoji et illustration
- produire des images trop chargees pour le mobile

Exigences :

- une meme bible couleur
- une meme logique de lumiere
- une meme silhouette des personnages
- une meme qualite de finition

## Critères De Réussite

La refonte est reussie si :

- les categories se distinguent immediatement
- les personnages donnent envie de revenir
- les scenes terrain paraissent locales et plausibles
- le back-office gagne en clarté sans perdre en legerete
- l ensemble est assez fort pour un effet "wow" de demonstration

## Décision Produit

`Awa` en V1 n etait qu une premiere presence editoriale.

La cible V2 n est pas une simple carte de texte mieux redigee.
La cible V2 est un univers visuel complet :

- duo mascotte + agent
- systeme d icones propre
- badges categories distincts
- illustrations terrain premium
