# Integration Visuels Produit Ma Commune

## But

Faire le lien entre les assets a produire et les surfaces reelles du produit.

Cette note evite deux erreurs :

- produire de belles images sans point d integration clair
- integrer des visuels au hasard sans logique UX

## Règle D Integration

Un visuel n est branche que s il remplit au moins une fonction :

- orienter
- rassurer
- remercier
- rendre une categorie plus lisible
- donner une presence premium a une surface cle

## Definition De Fini

Une integration est reussie si :

- le visuel a une fonction claire
- la surface gagne en lisibilite ou en desirabilite
- la performance reste correcte
- la meme logique visuelle traverse mobile, admin et site
