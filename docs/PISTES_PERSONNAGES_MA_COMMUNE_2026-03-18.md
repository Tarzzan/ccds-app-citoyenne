# Pistes Personnages Ma Commune

## But

Passer d une intention abstraite a des pistes concretes de production pour le duo visuel `mascotte + agent communal`.

Cette note sert a :

- choisir une direction de personnage
- preparer les prompts de generation IA
- lancer ensuite des planches coherentes

## Rappel De Cible

Le duo doit rendre `Ma Commune` :

- plus memorable
- plus humaine
- plus premium
- plus lisible

Il ne doit pas rendre le produit :

- infantile
- gadget
- folklorique
- confus

## Pistes Mascotte

### Piste M1 - Oiseau Vigie Tropical

Description :

- une petite vigie du territoire
- vive, attentive, chaleureuse
- bec et silhouette tres lisibles
- posture d observation et d accompagnement

Forces :

- lecture immediate en petit format
- fort potentiel icone / sticker / onboarding
- tres bon lien avec l idee de veille territoriale

Risques :

- peut devenir trop mignon si mal dirige

Usage recommande :

- accueil
- remerciement
- notifications positives
- etats vides

Prompt de base :

```text
Mascotte civique premium pour application mobile de service public local en Guyane francaise,
petit oiseau vigie tropical stylise, semi-realiste, chaleureux, silhouette tres lisible, regard intelligent,
lumiere tropicale douce, palette foret-fleuve-laterite, rendu cinematographique propre, premium, pas enfantin,
pas de style emoji, pas de clipart, fond simple ou detachable.
```

### Piste M2 - Gardienne Du Territoire

Description :

- creature symbolique plus elegante
- plus emblematique que mignonne
- ancre davantage l idee de territoire commun

Forces :

- identite marque forte
- potentiel hero de landing
- bonne stature institutionnelle

Risques :

- moins immediate emotionnellement
- plus difficile a deployer dans les petites interfaces

Usage recommande :

- landing
- splash
- ecrans hero
- communication premium

Prompt de base :

```text
Mascotte territoriale premium pour application civique locale en Guyane francaise,
figure symbolique elegante et attachante, semi-realiste, chaleureuse, silhouette iconique, expression bienveillante,
palette tropicale maitrisee, lumiere cinematographique douce, rendu premium, pas de style enfantin, pas de folklore caricatural,
fond simple ou scene territoriale epuree.
```

### Piste M3 - Compagnon Urbain Tropical

Description :

- animal stylise plus doux et incarnable
- tres expressif
- forte capacite narrative

Forces :

- excellent pour scenes de gratitude et suivi
- grande richesse d expressions
- fort potentiel social et marketing

Risques :

- peut perdre l ancrage territorial si le design est trop generique

Usage recommande :

- onboarding
- cartes d aide
- ecrans de suivi
- messages de remerciement

Prompt de base :

```text
Mascotte premium pour application mobile de service public territorial en Guyane francaise,
compagnon animal tropical stylise, semi-realiste, expressif, chaleureux, memorable, tres lisible,
lumiere tropicale douce, palette verte, sable, laterite, rendu premium et cinematographique, pas de style web generique,
pas de style emoji, fond simple ou detachable.
```

## Pistes Agent Communal

### Piste A1 - Agent Voirie De Proximite

Description :

- agent de terrain rassurant
- posture calme
- vetement municipal sobre
- presence de service public tangible

Forces :

- tres credible pour les categories terrain
- utile pour expliquer le suivi d un dossier
- bonne projection commerciale

Risques :

- peut sembler trop specialise si seul personnage humain produit

Usage recommande :

- detail signalement
- dossier en cours
- validation d execution
- admin et supervision

Prompt de base :

```text
Agent communal de terrain premium pour application mobile de service public local en Guyane francaise,
semi-realiste, bienveillant, credible, posture professionnelle, tenue municipale sobre, lumiere tropicale douce,
palette verte et terre, rendu cinematographique premium, pas rigide, pas corporate froid, pas photo brute,
fond simple ou scene territoriale lisible.
```

### Piste A2 - Agente Relation Usager

Description :

- presence plus pedagogique
- plus orientee accueil et explication
- lien direct avec le citoyen

Forces :

- parfaite pour messages de guidance
- ton plus humain et moins technique
- bonne complementarite avec une mascotte animale

Risques :

- moins terrain si elle reste seule

Usage recommande :

- connexion
- onboarding
- suivi d etapes
- notifications explicatives

Prompt de base :

```text
Agente communale premium de relation usager pour application de service public local en Guyane francaise,
semi-realiste, chaleureuse, credible, expressive, posture d explication et de reassurance, tenue municipale sobre,
lumiere tropicale douce, palette naturelle, rendu premium, pas corporate froid, pas cartoon enfantin.
```

## Duo Recommande Pour Premier Test

Le meilleur premier couple a explorer est :

- `M1 - Oiseau vigie tropical`
- `A2 - Agente relation usager`

Pourquoi :

- meilleur equilibre entre memorisation et confiance
- tres bon potentiel mobile
- forte complementarite emotion / explication
- peu de risque de rigidite institutionnelle

## Scènes Test A Produire D Abord

Pour choisir vite, ne pas lancer tout de suite trop d images.
Produire d abord :

- mascotte seule en portrait
- mascotte en geste de remerciement
- agent seul en buste
- agent en geste d explication
- duo sur un ecran d accueil
- duo devant une scene de voirie degradee

## Critères De Choix Final

On retient la piste qui :

- reste lisible en petit
- donne envie de revenir dans l app
- inspire confiance a un adulte
- reste premium sur landing et mobile
- s integre naturellement aux categories terrain
