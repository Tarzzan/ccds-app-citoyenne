# Planches Generation Badges Categories Batch 01

## But

Produire le premier lot de `badges categories V2` pour `Ma Commune`.

Ce lot doit sortir definitivement de l ambiguite entre :

- icone fonctionnelle
- emoji
- vignette illustrative

Le badge categorie V2 doit rester :

- tres lisible en petit
- premium
- narratif sans devenir une illustration complete
- compatible mobile, admin et landing

## Regles

- un badge garde un sujet unique et tres clair
- pas de texte dans l image
- pas de rendu emoji
- pas de clipart plat
- silhouette et point focal lisibles a petite taille
- palette ancree dans la categorie et le territoire

## Criteres De Validation

Chaque badge est valide seulement si :

- lisible a `40 px`
- identifiable sans texte
- distinct de tous les autres badges
- coherent avec l illustration terrain associee
- plus premium que le set actuel

## Usage Cible

- mobile : listes, fiches, selection de categorie
- admin : tableaux, detail, carte, configuration categories
- site : modules de promesse et cartes categories
