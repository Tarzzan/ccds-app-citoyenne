# Planches Generation Hero Commercial Batch 01 Ma Commune

## But

Définir les visuels les plus exposés commercialement :

- hero landing publique
- hero stores mobile

Ces images doivent produire l effet `wow` sans tomber dans la surenchère.

## Règles Communes

Contraintes :

- premium
- semi-réaliste
- émotionnel
- très lisible
- localement ancré
- pas de texte dans l image
- pas d effet institutionnel froid

Bloc style commun :

```text
semi-realistic premium civic illustration, warm tropical light, cinematic composition, strong silhouette,
French Guiana setting, lush vegetation, humid atmosphere, natural textures, polished details,
mobile-friendly readability, emotionally engaging, not childish, not flat clipart, no text in image
```

Negative prompt commun :

```text
text, watermark, logo, childish cartoon, flat clipart, generic smart city cliché, futuristic sci-fi city,
overcrowded composition, photorealistic photo look, cold corporate scene, european dry climate look
```

## HERO-01

### Usage

- page de garde `netetfix.com`
- hero commercial principal

### Fonction

- donner immédiatement le sentiment d un produit premium
- faire comprendre la promesse sans texte dans l image
- montrer le territoire et le duo visuel

### Composition

- duo personnage visible
- présence claire du territoire guyanais urbain/tropical
- élément terrain ou service public local perceptible
- espace respirant pour superposer du texte HTML ensuite

### Emotion

- confiance
- fierté locale
- proximité

### Ratio

- `16:9`

### Nom de sortie

- `hero-01-landing-ma-commune-16x9.png`

### Prompt

```text
Premium civic hero illustration for a public-service platform in French Guiana,
a warm municipal agent and a memorable tropical mascot standing in a lush urban-tropical local environment,
subtle signs of public-space care and civic attention, cinematic warm light, polished premium rendering,
clear readable silhouettes, strong emotional trust, enough negative space for website text overlay, no text
```

## HERO-02

### Usage

- stores mobile
- kit commercial
- presentation produit

### Fonction

- vendre l application en quelques secondes
- rendre la marque mémorable
- faire sentir la qualité et l humanité

### Composition

- duo plus proche
- lecture très rapide
- fond plus simple que le hero landing
- compatible recadrage store

### Emotion

- engagement
- accueil
- utilité

### Ratio

- `9:16`

### Nom de sortie

- `hero-02-store-ma-commune-9x16.png`

### Prompt

```text
Premium app-store hero illustration for a civic mobile app in French Guiana,
close and highly readable duo of a warm municipal agent and a memorable tropical mascot,
semi-realistic, cinematic warm light, polished rendering, elegant tropical palette,
emotion of welcome and useful civic action, simplified premium background suitable for mobile store artwork, no text
```

## Variantes A Prévoir

Si les premiers rendus sont bons :

- variante `HERO-01B` avec scène plus orientée voirie
- variante `HERO-02B` avec duo en posture de remerciement
- crop carré pour réseaux sociaux ou favicon éditorial

## Critères De Validation

Un hero est retenu si :

- il donne immédiatement envie d ouvrir l app
- il reste compréhensible sans texte
- il semble local et crédible
- il paraît premium sans surjouer le spectaculaire
- il peut recevoir du texte par-dessus sans perdre sa lisibilité
