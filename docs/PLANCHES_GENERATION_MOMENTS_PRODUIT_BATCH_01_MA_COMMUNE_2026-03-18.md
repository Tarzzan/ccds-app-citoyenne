# Planches Generation Moments Produit Batch 01 Ma Commune

## But

Definir les illustrations editoriales des moments les plus sensibles du produit.

Ce batch couvre :

- accueil
- remerciement apres signalement
- dossier en cours
- dossier resolu
- aucun signalement utile
- aucune notification importante

## Regles Communes

Contraintes de style :

- semi-realiste
- premium
- chaleureux
- mobile-first
- lisible rapidement
- pas de texte dans l image
- pas d effet gadget

Bloc style commun :

```text
semi-realistic premium civic illustration, warm tropical light, cinematic composition, strong silhouette,
French Guiana setting, lush vegetation, humid atmosphere, natural textures, polished details,
mobile-friendly readability, emotionally engaging, not childish, not flat clipart, no text in image
```

Negative prompt commun :

```text
text, watermark, logo, flat emoji style, childish cartoon, low detail, clipart, distorted anatomy,
overcrowded composition, exaggerated comedy, cold corporate atmosphere, photorealistic photo look
```

## Declinaisons A Prévoir

Pour chaque moment retenu :

- crop `3:4` mobile
- crop `16:9` hero si utile
- version fond simplifie si l interface l exige

## Criteres De Validation

Une illustration moment produit est validee si :

- elle clarifie l etat sans texte
- elle augmente la confiance
- elle ne parait ni infantile ni publicitaire
- elle s integre naturellement a une interface sobre
