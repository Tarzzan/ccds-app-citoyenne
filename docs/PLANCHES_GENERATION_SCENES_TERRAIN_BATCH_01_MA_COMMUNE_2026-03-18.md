# Planches Generation Scenes Terrain Batch 01 Ma Commune

## But

Préparer le premier lot des 8 scènes terrain prioritaires avec un niveau de précision suffisant pour une production cohérente.

Chaque fiche précise :

- le sujet exact
- le point focal
- l émotion recherchée
- le cadrage
- le ratio
- le nommage de sortie

## Règles Communes

Contraintes de style :

- semi-réaliste
- premium
- tropical
- mobile-friendly
- pas de texte
- pas d emoji
- pas de rendu photo brut
- pas de surcharge visuelle

Bloc style commun :

```text
semi-realistic premium civic illustration, warm tropical light, cinematic composition, strong silhouette,
French Guiana setting, lush vegetation, humid atmosphere, natural textures, polished details,
mobile-friendly readability, emotionally engaging, not childish, not flat clipart, no text in image
```

Negative prompt commun :

```text
text, watermark, logo, flat emoji style, childish cartoon, low detail, clipart, distorted perspective,
blurry subject, overcrowded composition, generic european city, dry climate look, photorealistic photo look
```

## Déclinaisons A Prévoir Après Validation

Pour chaque illustration retenue :

- crop `3:4` mobile hero
- crop `1:1` miniature categorie
- version fond simplifié si besoin UI

## Critères De Relecture

Pour valider une scène :

- le sujet se comprend en moins de 2 secondes
- le territoire paraît crédible
- la lumière et la palette restent cohérentes
- la scène reste exploitable en recadrage mobile
