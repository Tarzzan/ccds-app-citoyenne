# Prompts Production Visuels Ma Commune

## But

Poser un premier pack de prompts directement reutilisables pour produire les personnages et les scenes prioritaires.

Ces prompts sont des bases.
Ils devront etre ajustes apres choix du duo final.

## Contraintes Globales

A rappeler dans chaque prompt si necessaire :

- application mobile premium de service public local
- Guyane francaise
- semi-realiste
- cinematographique
- chaleureux
- lisible en mobile
- pas d emoji
- pas de texte integre
- pas de style enfantin
- pas de clipart

## Bloc Style Global

```text
semi-realistic premium civic illustration, warm tropical light, cinematic composition, strong silhouette,
French Guiana setting, lush vegetation, humid atmosphere, natural textures, polished details,
mobile-friendly readability, emotionally engaging, not childish, not flat clipart, no text in image
```
