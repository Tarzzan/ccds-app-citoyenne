Configuration locale de démonstration

Cette page remplace l'ancien guide adossé à un sandbox externe. Elle décrit uniquement le mode de configuration réellement vérifié localement pour la démonstration de Ma Commune, sur poste de développement et future validation tablette.

API locale http://127.0.0.1:8080/api
Admin web http://127.0.0.1:8080/admin/?page=login
Pré-vol bash scripts/audit_local_predeploy.sh

Ce que couvre ce guide

Le parcours réellement maintenu est celui de la démonstration locale: configuration serveur, connexion citoyenne, suivi d'un signalement, supervision admin, consultation et agenda communal.

Ce que ce guide ne fait plus

Il ne pointe plus vers de sandbox Manus, d'URL temporaires ni de comptes historiques de démonstration publique. Toute la chaîne repose sur les services locaux vérifiés.

État actuel

Le projet n'est pas encore validé une dernière fois sur tablette dans cette phase. La référence opérationnelle reste l'audit local et les modes opératoires du dépôt.

1. Préparation obligatoire

Avant une démonstration ou une revalidation fonctionnelle, exécuter:

bash scripts/audit_local_predeploy.sh
bash scripts/seed_demo_local.sh

L'audit doit finir par Toutes les verifications critiques sont passees.. Le seed doit ensuite produire un bloc DEMO READY avec les comptes citoyens, les incidents, la consultation active et le rendez-vous communal.

2. Configuration de l'application mobile

  1. Ouvrir l'application Ma Commune.
  2. Sur l'écran Configuration serveur, saisir http://127.0.0.1:8080/api.
  3. Lancer Tester la connexion.
  4. Enregistrer uniquement si le test est valide.
En débogage USB, le même endpoint est utilisé si l'appareil est raccordé via adb reverse tcp:8080 tcp:8080. Cette étape tablette n'est pas rejouée dans la phase actuelle.

3. Comptes à utiliser

Les comptes citoyens de démonstration sont générés par le seed avec un domaine plus présentable @macommune.local.

  • demo.citoyen.a.<timestamp>@macommune.local
  • demo.citoyen.b.<timestamp>@macommune.local
  • demo.citoyen.c.<timestamp>@macommune.local
  • Mot de passe commun: Citoyen@MaCommune2026!

Les comptes techniques de démonstration utilisent désormais aussi le domaine local @macommune.local pour garder une démonstration plus cohérente.

4. Parcours conseillé de démonstration

  1. Montrer côté citoyen un dossier soumis, un dossier en cours et Mon bilan.
  2. Montrer côté agent la prise en charge, la priorité et le commentaire public.
  3. Montrer côté admin le dashboard, la supervision du dossier, la consultation active et l'événement.
  4. Revenir sur le compte citoyen pour valider notifications, suivi et cohérence de l'historique.
